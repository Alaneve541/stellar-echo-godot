   # 星海回响 - 3D 第一人称战斗 Demo



基于 Godot 4 + GDScript 开发的 3D 第一人称动作游戏 Demo，包含账号系统、战斗系统、装备成长、多波次刷怪、Boss 战与联网排行榜。

   ### 账号系统

   - 注册 / 登录

   - JSON 存档，记录等级、经验、最大生命、攻击力、背包、技能等级、成就、每日任务

   - 最高波次、总击杀数统计



   ### 战斗系统

   - 第一人称移动（WASD）+ 跳跃（空格）+ 鼠标视角

   - 普通攻击（鼠标左键），使用 RayCast3D 判定

   - 4 个技能：

&#x20; - 1 重击：2 倍伤害

&#x20; - 2 散射：5 米范围内群体伤害

&#x20; - 3 回复：恢复 20-35 生命

&#x20; - 4 爆发：10 米范围内大量伤害

   - 技能冷却机制

   - 技能升级（消耗经验提升伤害、降低冷却）



   ### 敌人 AI

   -    *   *近战敌人   *   *（红色）：追击玩家，近身攻击

   -    *   *远程敌人   *   *（紫色）：保持 6-10 米距离，发射子弹

   -    *   *快速敌人   *   *（黄色）：高速追击，血量低

   -    *   *自爆敌人   *   *（橙色）：靠近玩家后自爆，伤害高

   - 敌人类型随波次逐步解锁



   ### Boss 战

   - 每 5 波刷新一次 Boss

   - Boss 拥有 4 个技能，按顺序循环释放：

&#x20; - 范围爆炸：8 米内造成伤害

&#x20; - 召唤小怪：召唤 2 个快速敌人

&#x20; - 冲锋：高速冲撞玩家

&#x20; - 弹幕：扇形发射 8 发子弹

   - 血量低于 50% 进入二阶段，速度提升、技能冷却缩短

   - Boss 血条显示在屏幕顶部



   ### 波次系统

   - 每波敌人数量递增

   - 清完一波后 3 秒刷新下一波

   - 每 5 波为 Boss 波



   ### 装备系统

   - 6 个装备槽位：武器、护甲、头盔、鞋子、戒指、项链

   - 4 种品质：普通、稀有、史诗、传说（属性递增）

   - 掉落随机品质装备

   - 按 E 一键穿戴背包内所有装备

   - 装备提供攻击力和生命值加成



   ### 商店

   - 按 B 打开

   - 用材料兑换装备

   - 6 件普通品质装备可购买



   ### 成就系统

   - 按 J 打开

   - 11 个成就，涵盖击杀、波次、等级、传说装备

   - 达成后自动解锁并保存



   ### 每日任务

   - 按 K 打开

   - 每天刷新 3 个任务

   - 任务类型：击杀、波次、技能使用、装备掉落、经验消耗

   - 完成给经验和材料奖励



   ### 排行榜

   - 主菜单查看

   - 联网排行榜，通过 HTTP API 上传到云端

   - 多客户端共享数据

   - 本地 JSON 备份，联网失败自动降级



   ### 音效

   - BGM + 攻击 / 技能 / 受击 / 死亡音效

   - 使用 AudioStreamPlayer + Audio Bus 分离 BGM 和音效

   - 音量设置可调，保存到本地



   ## 操作说明



| 按键 | 功能 |

|------|------|

| WASD | 移动 |

| 空格 | 跳跃 |

| 鼠标移动 | 视角 |

| 鼠标左键 | 普通攻击 |

| 1 | 重击 |

| 2 | 散射 |

| 3 | 回复 |

| 4 | 爆发 |

| E | 打开背包（面板打开时再按 E 一键穿戴） |

| B | 打开商店 |

| U | 打开技能升级 |

| J | 打开成就 |

| K | 打开每日任务 |

| Esc | 关闭面板 / 保存并返回登录 |



   ## 技术栈



   -    *   *引擎   *   *：Godot 4

   -    *   *语言   *   *：GDScript

   -    *   *数据存储   *   *：JSON

   -    *   *联网   *   *：HTTPRequest + REST API
